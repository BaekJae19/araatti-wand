# 케이스 설계 주요 단계

최종본 외에 초기 설계와 구조가 크게 바뀐 시점 두 개만 보관한다. 모든 시험 버전과 Blender 이전 저장본(`.blend1`)을 모은 백업은 아니다.

| 단계 | 작업 시점 | Blender 원본 | 보관 이유 |
|---|---|---|---|
| Meshy 기반 초기 케이스 | 2026-09-11 ~ 09-13 | [controller_case.blend](01_meshy_initial/controller_case.blend) | 170mm 유기 형상을 전후 2피스 케이스로 가공한 초기안. 씬에 Meshy 원본과 중간 형상도 남아 있다. |
| 파라메트릭 재설계 v4 | 2026-09-21 | [wand_v4.blend](02_parametric_v4/wand_v4.blend) | 회전체 기반 재설계 후 평평한 바닥, USB-C 슬롯, 손가락 링과 조작부 마운트까지 적용한 실물 출력 버전. 이후 수납·조립 문제를 고친 최종본과 비교하기 위한 기준이다. |
| 최종 케이스 | 2026-09-23 | [wand_v7_ledge.blend](../wand_v7_ledge.blend) | 기존에 보관한 최종본. 출력용 파일은 [case/stl](../stl)에 있다. |

## 설계가 바뀐 순서

1. Meshy 기반 170mm 케이스를 가공했다.
2. 부품 실측과 별도 테스트 박스로 수납·공차를 확인했다.
3. 부위마다 치수를 바꾸기 어려운 기존 메시를 대신해 v2부터 프로파일 회전체로 재설계했다.
4. v4에서 바닥을 평탄화하고 USB-C 슬롯, 손가락 링, 조이스틱·버튼 마운트와 립 제거를 반영했다. 전장은 140.5mm, 그립은 Ø35mm, 헤드 폭은 약 71mm였다.
5. 실물 조립 피드백을 반영해 v5에서 그립 Ø38mm·헤드 폭 약 83mm로 확대했다. v6에서는 삽입할 수 없는 FSR 플런저를 없애고 조이스틱 주변 벽과 마운트를 수정했다.
6. v7에서 내부 간격을 늘리고 손잡이를 20mm 연장했다. 기존 최종 보관본은 이후 저장한 `v7_ledge`다. 그 접미사에 해당하는 세부 변경 내용은 기존 작업 기록에 명시되어 있지 않다.

## STL 보관 방식

- 각 단계의 `stl/`에는 해당 Blender 원본의 케이스·버튼 부품만 내보냈다. 비교용 솔리드, 커터, Meshy 원본은 제외했다.
- 초기안은 `CTRL_FRONT`, `CTRL_BACK`, `BTN_A`, `BTN_B` 4개, v4는 `FRONT`, `BACK`, `CAP_A`, `CAP_B`, `PLUNGER` 5개다.
- 이 STL들은 과거 출력 파일을 찾은 것이 아니라 **2026-11-26에 보존된 Blender 원본에서 다시 추출한 파일**이다. Blender 파일 자체는 원본과 바이트 단위로 동일하다.
- STL 좌표는 mm 기준이다. 두 Blender 파일의 scene unit scale이 달라 단위 자동 변환을 끄고, 원본의 숫자 치수를 그대로 유지했다. 삼각형 수, 파일 길이, 각 축의 외곽 치수가 원본과 일치하는지 확인했다.
- 초기안과 v4는 설계 이력용이다. 특히 v4의 FSR 플런저 삽입 문제와 조이스틱 주변 벽 문제는 후속 버전에서 수정됐다. 실제 제작에는 최종본을 사용한다.
- 이 폴더의 `.blend`와 `.stl`은 Git LFS로 보관한다. 복원 시 `git lfs install` 후 `git lfs pull`로 원본 파일을 받는다.

선정 근거: 로컬 작업 정리, 당시 케이스 설계 메모, 각 Blender 파일의 실제 오브젝트와 치수.
